## Entregas

Cada equipo dispone de su propio repositorio privado.

Podéis organizar vuestro trabajo en GitHub como prefiráis. La única condición es que, en la fecha límite de cada hito, **la versión que queráis entregar debe estar integrada en `main`**.

La entrega quedará registrada a partir de ese estado del repositorio.
